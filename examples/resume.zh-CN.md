## 代表项目

### Agent 权限与发布治理

- **项目背景：** 企业客户需要在不同部门、群聊和渠道中控制 Agent 的发布与使用范围。
- **个人贡献：** 梳理可见、可用、可发布、可审计四类规则，推动产品入口、配置页和审核流程保持一致。
- **结果表达：** 形成可验收的权限规则和交互方案，为后续 Agent 平台化管理提供基础。

### 工作流条件循环

- **项目背景：** 自动化场景需要支持重复执行、条件退出和异常处理，但原有配置方式难以表达复杂流程。
- **个人贡献：** 将循环语义拆成触发条件、循环体、退出条件和异常状态，并补充预览与校验规则。
- **结果表达：** 帮助产品、研发、测试对流程边界形成统一理解，减少实现和验收歧义。

### Lark Resume Skill

- **项目背景：** 简历生成通常依赖个人回忆，容易遗漏真实贡献或夸大结果。
- **个人贡献：** 设计基于飞书群聊、单聊、文档和项目记录的证据检索与简历生成流程，要求生成前确认语言、流程、任职时间和最终格式。
- **结果表达：** 输出可复用 Skill，支持 Brief、Markdown、DOCX、SVG 和 HTML 多种形态。
