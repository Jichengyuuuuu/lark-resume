## 代表项目

### Agent Runtime 执行框架

- **项目背景：** 多个 Agent 应用各自维护执行逻辑，任务状态、工具调用和失败恢复方式不一致，影响交付稳定性。

- **结果表达：** 支撑多个 Agent 应用复用同一执行框架，降低重复实现和线上排障成本。

### Tool Calling 网关

- **项目背景：** Agent 需要调用外部 API、内部服务和本地脚本，但不同工具的鉴权、入参、超时和错误格式差异较大。

- **结果表达：** 提升工具接入一致性，让开发者可以用同一套方式完成本地调试和线上调用。

### Agent 评测流水线

- **项目背景：** Agent 行为受模型、提示词和工具状态共同影响，常规单元测试难以覆盖规划偏移和工具误用。

- **结果表达：** 帮助团队在发布前发现格式回归、工具误用和任务失败案例，提升迭代可控性。
